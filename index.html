    새 멤버는 Supabase 대시보드 → Authentication → Users → Add user 에서 추가합니다.
    ① Send invitation: 이메일로 초대 링크 발송 → 멤버가 링크를 누르면 이 사이트에서 이름·비밀번호를 정함 (기본 메일 발송은 시간당 몇 건으로 제한되니 한 번에 여러 명이면 ②)
    ② Create new user: 이메일 + 임시 비밀번호 입력, Auto confirm 체크 → 멤버에게 임시 비밀번호를 알려주면 로그인 후 상단 이름 클릭 → "내 정보"에서 이름과 비밀번호를 바꿀 수 있음
